## 操作

| 按键 | 功能 |
|---|---|
| `W/A/S/D` | 移动 |
| 鼠标左键（单击） | 锁定指针——**锁定后才能用鼠标转向视角** |
| 鼠标移动 | 转向视角（仅指针锁定时生效） |
| 鼠标左键（按住） | 挖掘准星处的方块（`1.5s × 方块硬度 ÷ 工具速度`）；若准星对准 mob = 攻击（每 0.25s 一击） |
| 鼠标右键 | 按选中物品：放置方块 / 吃东西 / 拉弓蓄力（松手射出）/ 打开工作台面板 |
| `Space` | 跳跃（贴地时）；水中 = 上浮 |
| `LeftShift` | 冲刺（5.6 块/秒，行走 4.3） |
| `LeftControl` | 潜行（身位降低、不自动迈 1 格台阶、防跌落边缘） |
| `Tab` | 循环切换热栏选中格 |
| `Q` | 丢弃选中格物品（落地为掉落物） |
| `E` | 打开背包 + 合成面板（2×2 合成格 + shapeless 配方列表） |
| `F3` | 调试信息（坐标/朝向/时间/难度/FPS 等） |
| `F5` | 立即存档（仅 `--save` 运行时有效） |
| `R` | 死亡后重生 |
| `ESC` | 解锁指针 / 关闭窗口退出 |

## 生存循环

1. **白天是安全的**（zombie 和 skeleton 只在黑暗处生成）。挖树（`wood`）→
   合成木板/木棍/工具（见下）；挖矿石获得材料（煤/铁/金/钻石直接掉对应材料）。
2. **天黑前做好准备**：夜里 zombie（贴身近战）和 skeleton（远距离射箭）会
   生成并追杀你，树冠/洞穴的暗格里白天也会生成。世界出生点周围有保护环
   （按难度 8/12/16 块），敌对 mob 不会在环内自然生成。
3. **饥饿**：饥饿值 20，每 4 秒自然衰减 1 点——但衰减先消耗隐藏的**饱和度**
   缓冲（吃东西时按 2× 恢复量充入，缓冲耗尽才掉饥饿条，即"吃饱了饿得慢"）；
   **疾跑**（`Shift` + 移动）时衰减速率 ×2；饥饿到 0 后每 4 秒掉 1 HP（饿死）。
   回复饥饿 = 吃东西（见下）。
4. **回复生命**：脱离受伤 10 秒后，若饥饿 ≥ 6，每 4 秒自动回 1 HP。
5. **死亡**：HP 归零 → 画面冻结显示 "You died! / Press R"，按 `R` 回出生点
   重生（满血 + 满饥饿 + 满饱和度，**背包保留**）。坠落（净下落 > 3 格）和掉出
   世界（y < −32）都会致命。

## 战斗与食物

- **攻击**：左键按住挥击，伤害 = **选中物品**的 `attack_damage`（徒手/方块/
  材料 = 1，木镐 = 2，铁镐 = 3，弓近战 = 1），命中 mob 还会击退它。
  带**虚弱**效果时近战伤害相应降低（虚弱的徒手打出 0 伤害）。
- **杀 mob 掉物品**（走近掉落物自动拾取，0.5s 拾取延迟；每只 mob 的数据可定义
  **多个掉落**，死亡时按列表顺序各掉一件）：
  | mob | HP | 掉落 | 用途 |
  |---|---|---|---|
  | zombie（夜晚/黑暗） | 20 | `rotten_flesh` | **食物**（+4 饥饿） |
  | skeleton（夜晚/黑暗） | 20 | `arrow` | 弓的弹药 |
  | cow（白天夜晚均可） | 10 | `leather` + `beef` | 材料 + **食物**（+3 饥饿） |
  | sheep | 8 | `wool` + `mutton` | 材料 + **食物**（+2 饥饿） |
  | chicken | 4 | `feather` + `chicken` | 材料 + **食物**（+2 饥饿） |
- **箭**（skeleton 掉落 / 2 stick 合成）：插在方块上的箭**走近即拾取**（1.0 块
  内，返还 1 支箭；飞行中的箭拾不了）；箭插着的**方块被破坏时箭会掉下来**
  （落地后可拾取）；插墙箭停留 100 秒后消散。箭命中的击退**随拉弓蓄力**
  变化——拉得越满击退越强（满蓄力 = 最强）。
- **吃东西**：选中食物后**按住右键 1.6 秒** = 吃（3D 手部随进度抬向面部；
  **中途松开 = 取消不吃**，受击/死亡/解锁鼠标/开面板/换物品/左键挥击同样取消且
  **不消耗食物**；完成时回复数据点饥饿 + 2× 饱和度、
  消耗 1 个、播放进食音）。食物共 4 种：`rotten_flesh`（+4）、`beef`（+3）、
  `mutton`（+2）、`chicken`（+2）。满饥饿时右键食物 = 无效果（仍吞掉该次右键）。
  所以生存闭环是：**打/杀 mob → 吃掉落肉 → 撑过夜晚**（被动 mob 也是食物来源）。

## 工具与合成路线

- **E 面板**（2×2 格 + 左侧 shapeless 配方列表，点配方直接合成）：
  - `wood` → 木板 ×4；木板 ×2 → 木棍 ×4；木板 2×2 → 工作台
  - 燧石 + 木棍 + 羽毛 → 箭 ×4（Phase 60，MC 1.14+；羽毛 = 杀鸡掉落）
  - 煤 + 木棍 → 火把 ×4（Phase 65，MC；煤 = 煤矿石掉落）
  - 燧石 + 铁锭 → 燧石与钢（Phase 60）
  - 锻石 ×4 → 石头（Phase 61，MC 材料循环）
- **石头→锻石循环**（Phase 61，Minecraft 同款）：挖**天然石头**掉
  **锻石（cobblestone）**；锻石 ×4 合成回石头（不能熔炼回 = 见
  KNOWN_ISSUES 的文档化偏离）。
- **工作台**（右键放置的工作台，3×3 格）：
  - 木镐（木板 3 + 木棍 2，镐形）——挖掘速度 ×2（**石类/矿类 ×2 = ×4**，
    Phase 69）、攻击 2
  - 石镐（锻石 3 + 木棍 2，镐形）——挖掘速度 ×3（石类/矿类 ×2 = ×6）、
    攻击 2.5（Phase 62，镐路线中档；锻石 = 挖天然石头掉落）
  - 铁镐（铁锭 3 + 木棍 2）——挖掘速度 ×4（石类/矿类 ×2 = ×8）、攻击 3
    （铁锭 = 挖铁矿石）
  - 木斧（木板 2 + 木棍 2，L 形）——对**木头/树叶 ×2**（其它块 = 手速）、攻击 3（Phase 67）
  - 石斧（锻石 2 + 木棍 2）——同上、攻击 3.5（锻石 = 第二个工具用途）
  - 铁斧（铁锭 2 + 木棍 2）——同上、攻击 4
  - 木铲（木板 1 + 木棍 2，竖列）——对**泥土/草/沙/砂砾 ×2**（其它块 = 手速）、攻击 2.5（Phase 68）
  - 石铲（锻石 1 + 木棍 2）——同上、攻击 3（锻石 = 第三个工具用途）
  - 铁铲（铁锭 1 + 木棍 2）——同上、攻击 3.5
  - 砂岩（沙 3 → 1，Phase 80——压缩沙，MC 同款材料链）
- 光滑砂岩（砂岩 2 → 1，Phase 81——抛光砂岩，MC 1.14+ 同款）
- 弓（木棍 3 + 木板 1，C 形）
- **弓的用法**：选中弓**按住右键**拉弓（1.6s 满蓄力），**松手射出**——
  伤害/速度 = 5 × 威力 / 15 × 威力（快速点射 = 最低威力 0.1）；每支箭消耗 1 个
  `arrow` 弹药（没有箭射不出去）；左键 = 弓近战（伤害 1，永不挖掘）。
- **无限弓（infinite_bow，Phase 77）**：`弓 + 钻石` 工作台合成 1 个——
  **MC Infinity 附魔的可合成替身**。用法与弓完全相同，但**射箭不消耗
  弹药**：背包里只要有 1 支箭就能无限射（那 1 支箭永远不会少）。
  钻石 = 项目顶级材料，所以它仍是"高级"装备。
- **信标（beacon，Phase 83）**：见下方「信标」。
- **砂岩（sandstone，Phase 80）**：`3 个沙` 合成 1 个——压缩沙（MC
  同款材料链，三层纹理）。**镐挖 ×2**（石类家族成员），手挖 2.25 s、
  铁镐 0.28 s；破坏掉自己。沙只能从砂岩"反着走"回沙（无锻回配方，
  P61 锻石同款单向链）。
- **光滑砂岩（smooth_sandstone，Phase 81）**：`2 个砂岩` 合成 1 个——
  抛光砂岩（无三层切线，MC 1.14+ 同款），砂岩材料链的最后一环。
  属性与砂岩相同（**镐挖 ×2**、手挖 2.25 s、铁镐 0.28 s、破坏掉自
  己）。整条链 `沙 → 砂岩 → 光滑砂岩` 单向，无锻回。
- **力量弓 / 速度弓（Phase 79）**：`弓 + 2 钻石` → **力量弓**（箭伤害
  5 → 8，MC 力量附魔的可合成替身）；`弓 + 金锭` → **速度弓**（箭初速
  15 → 20，飞得更远更快）。用法与普通弓完全相同。想要"又强又快还不
  耗箭"得各做一把（项目无附魔台）。
- **大师弓（master_bow，Phase 82）**：`力量弓 + 速度弓 + 无限弓`
  工作台合成 1 个——三把强化弓**叠加**的顶点弓（MC 附魔台的合成替身）。
  箭伤害 8、箭初速 20、**射箭不耗弹药**（须持有 ≥1 支箭）。想要"又
  强又快还不耗箭"，把三把弓各做一把合起来就是它。

## 牛奶（Phase 43）

- **做桶**（工作台 shaped 配方）：3 个铁锭摆成 `I I` / ` I ` = `bucket`
  （空桶，堆叠上限 16）。
- **挤奶**：手持空桶**右键 cow** = 桶变 `milk_bucket`（奶桶）。cow 不受
  任何影响——不受伤不掉肉，想喝多少挤多少。背包满时挤不出（点击被吞）。
- **喝奶**：选中奶桶**按住右键 1.6 秒** = 喝（与吃食物同一套通道，中途
  松开取消不消耗）。喝完**不回复饥饿**（MC 牛奶饥饿值 = 0），但会**清除
  受击红闪 + 全部负面状态效果**（Phase 46：中毒/虚弱等；**正面的再生
  效果保留** = MC 语义）。注意**受击会中断饮用通道**（与进食同规则）——
  中毒时开喝若被毒 tick 打到，这次喝会被取消不消耗，毒发间隙再喝。
  空桶自动回到背包。

## 药水（SURV-4）

- **获取**：初始储物（`E` 面板 17-23 槽）= 玻璃瓶 ×4 + 6 种药水各 1
  （隐藏发放，同树苗）；无酿造台（记档偏离）。
- **喝**：选中药水**按住右键 1.6 秒**（与喝奶同一通道；受击/开面板/
  换手 = 中断不消耗）。喝完**返还 1 个玻璃瓶**到背包。
- **效果**（喝下即生效，图标 = 状态效果行）：
  - **治疗药水**：立即 +4 HP（上限 20）
  - **伤害药水**：立即 −6 HP（**护甲挡不住**——魔法伤害语义）
  - **再生药水**（0:45）/ **迅捷药水**（3:00 移速 1.2×）/
    **虚弱药水**（1:30 近战 −4）/ **中毒药水**（0:45，毒不死）
  - 同效果**再喝 = 重置时长**（不叠加）
- **瓶-水循环**：持玻璃瓶**右键 L8 水源** = 舀水成水瓶（水源移除，
  同桶语义）；持水瓶右键 = 倒回水源。水瓶是纯容器（不可喝，记档偏离）。

## 状态效果（Phase 46）

- **中毒**（spider 近战命中 15 秒 / 中毒药水 0:45，SURV-4）：每 2.5 秒
  掉 1 HP，**毒不会把你毒死**（最低保持 1 HP = MC 地板）。心行左侧出现
  紫色骷髅图标，F3 调试层有剩余秒数。
- **虚弱**（虚弱药水，SURV-4）：近战伤害 −4（虚弱的徒手打出 0
  伤害），图标 = 蓝色下箭。
- **再生**（金苹果吃时给 10 秒，Phase 49 / 再生药水 45 秒，SURV-4）：
  每 4.5 秒回 1 HP（与自然回复独立并存），图标 = 绿色上箭。
- **燃烧**（碰熔岩点燃，Phase 57）：每 0.2 秒掉 1 HP，**能烧死**；
  离开熔岩后**继续烧 8 秒**（残留燃烧，Minecraft 同款）；**进水立刻
  熄灭**（水胜熔岩：两流体并存时无火）。图标 = 橙色火焰。
- **牛奶**清除全部**负面**效果（见上「牛奶」）；**牛奶不灭火**（Minecraft
  一致——灭火只有水）；死亡清空全部效果；效果入存档（读档后剩余时长
  继续，读档续烧）。

## 水/熔岩桶（Phase 47，Phase 51 熔岩）

- **舀水/熔岩**：手持**空桶**右键**流体表面**（必须是"源头"——静止的一
  整格，level 8；流动的膜舀不到）= 流体被收进桶里，空桶变**水桶/熔岩
  桶**（"splash" 音效）。一个空桶两种都舀（MC 语义）。隔着一堵墙/流动
  膜舀不到（准星先打到别的东西）。
- **倒水/熔岩**：手持**满桶**右键**方块表面**（空地、不踩着自己）= 倒
  出一格源头流体，满桶变回空桶。倒出的流体随后正常流动/扩散——倒在半
  空中它会落下来，倒在平地它会摊开。
- **水 + 熔岩 = 石头/黑曜石**（MC 同款）：熔岩**挨着水**时反应——挨着
  的是**源头水** → 黑曜石；挨着的是**流动水** → 石头。水不被消耗。
  熔岩会**发光**（夜里也能照出熔岩池）。
- 桶**不能喝**（右键只舀/倒），桶永远不放方块。背包满时舀/倒不发生
  （点击被吞）。流体入存档（读档后你倒的水/熔岩还在）。
- 熔岩**会烧**（Phase 54）：站在熔岩格里**每秒受 4 HP 灼烧伤害**
  （Minecraft 速率，走正常伤害路径 = 红闪/音效/死亡全触发）；熔岩里移动
  比水里**明显更慢**（横移/上浮/下沉都是熔岩节奏）；掉进熔岩**取消坠落
  伤害**（与水同款）。碰熔岩还会**点燃**你（Phase 57 火系统，见上
  「燃烧」）：熔岩内直接灼烧 + 燃烧效果叠加（~9 HP/s，Minecraft 同款），
  **离开熔岩后继续烧 8 秒**，进水立刻熄灭。世界生成不产熔岩（只能靠
  桶/反应）。
- 熔岩**也烧 Mob 和可燃方块**（Phase 58）：Mob 踏入/接触熔岩即被
  **点燃**（每 0.2 秒掉 1 HP，与玩家同款节奏，能烧死；离熔岩继续
  烧 8 秒，进水熄灭）；可燃方块（作物小麦 7 阶 + 木头/树叶/草方块，
  Phase 63 = MC 天然可燃面）被熔岩 6-邻接触**烧成空**（无掉落）。
  水不烧任何东西。

## 小麦与面包（Phase 48）

- **种子**：破坏**草方块**主掉**泥土**，并有 **12.5% 概率**额外掉 1 个
  **小麦种子**（`wheat_1`，一株小苗；Minecraft 同款"草掉泥土 + 偶尔种子"）。
  破坏未熟的小麦（`wheat_1..6`）也掉 1 个种子（可再种）。手持种子右键
  **耕地的顶面** = 种下一株小麦——种子**只能种在耕地正上方**（放置
  受限：土壤不符时右键是 no-op，种子不消耗；Minecraft 同款约束）。
- **耕地**：工作台合成 **1 个泥土 → 1 个耕地**（无序配方）。手持耕地
  右键方块表面 = 铺一片耕地（和放方块同一套规则）。耕地是小麦的**必
  要土壤**：种子必须种在耕地**正上方**才会生长。耕地挖掉掉回泥土。
- **生长**：合格的小麦（下方是耕地 + 自身格光照 ≥9）会**自己长高**
  ——从矮苗（`wheat_1`）一阶阶长到金黄的成熟麦穗（`wheat_7`）。**浇
  水**：耕地 4 格内（同层）有任意一格水 = 湿润 = 正常速率（每阶平均
  6 秒，约 36 秒成熟）；**没水** = 干耕地 = 半速（每阶平均 12 秒）。
  **光照**：自身格光照（天空光/方块光的较大者）不足 9 不生长——麦地
  上盖石头/种在深坑里会停长，挖开顶盖恢复。水桶（Phase 47）在麦地旁
  倒下一桶水即可长期湿润（源格持续供水）。破坏**未熟**的小麦掉回种
  子（可再种）；破坏**成熟**的麦穗掉 **2 个小麦**（收获物）。
- **面包**：3 个小麦在工作台合成 1 个**面包**（无序配方，3 个放哪都行）。
  手持面包右键**按住约 1.6 秒**吃掉，恢复 5 点饥饿。
- 小麦/面包入存档（读档后你种的麦子按当时阶段还在，会继续长）。

## 苹果与金苹果（Phase 49）

- **苹果**：破坏**树叶**有 1/128 的概率额外掉 1 个**苹果**（主掉落仍是
  树叶本身，两者一起掉）。概率是**确定性**的——同一棵树同一位置每次
  破坏结果相同（不是随机数），多砍树总能攒到。苹果是食物：手持右键
  **按住约 1.6 秒**吃掉，恢复 4 点饥饿。
- **木棍**（Phase 55）：破坏树叶另有 **2% 概率**额外掉 1 个**木棍**
  （MC 1.14+ 同款概率；木棍用于箭/工具等配方，与木板合成来源并存）。
- **金苹果**：工作台 3×3 把 **8 个金锭围一圈、中间放 1 个苹果**合成 1 个
  **金苹果**（MC 同款镶金摆法，位置必须精确）。吃金苹果 = 恢复 4 点饥饿
  **+ 获得 10 秒再生**（见「状态效果」——每 4.5 秒回 1 HP）**+ 获得 5 秒
  吸收**（**4 点吸收池** = 心带左侧多出的 **2 颗红色心**；受伤**先扣
  红心再扣正常心**，红心扣完前正常心不受影响；5 秒到期后剩余的红心
  **无声消失**（正常心血量不变——红心不是真血，无伤害红闪）。受伤后
  的应急食物。
- 金苹果/苹果入存档（读档后还在；吃剩的再生/吸收剩余时长也继续；吸收
  池**单独入档**（Phase 72）——被扣掉的红心读档后**不会**自动回满，
  效果剩余时长内池保持扣减值，到期才消失）。

## 砾石与燧石（Phase 59；燧石用途 Phase 60）

- **砾石（gravel）**：地下**常见矿脉**（石替换脉，比任何矿石都常见），
  挖掘石头时有机会遇到；破坏后主掉**砾石本身**，并有 **10% 概率**额外
  掉 1 个**燧石（flint）**（Minecraft 同款概率）。概率是**确定性**的——
  同一格每次破坏结果相同（破坏-重放-再破坏不变），多挖总能攒到。
- **燧石（flint）**：两个用途（Phase 60，Minecraft 主用途）：**箭配方**
  （燧石 + 木棍 + 羽毛 → 箭 ×4）与**燧石与钢**（燧石 + 铁锭）；
  64 个一叠。
- **燧石与钢**：选中后**右键可燃块**（作物 wheat_1..7 + 木头/树叶/草方块，
  Phase 63 = MC 天然可燃面）= 该块**烧成火（fire）**、无掉落（与熔岩烧
  同款语义），物品**不消耗**（MC：燧石与钢用不坏）；右键炉子/工作台仍
  正常开面板。v1 只作用于块（Mob 点燃仍只来自熔岩，见 KNOWN_ISSUES）。
- **火（fire，Phase 64；Phase 66 粒子 + 蔓延）**：可燃块被点燃器或熔岩
  烧掉后**留下的火焰块**——**光 15 的光源**（夜里看得见），几秒后
  **自己燃尽**（`fire.lifetime_seconds`，默认 4 秒），**浇水立刻灭**
  （6 邻有水即灭）；破坏/燃尽都不掉东西。fire 也能自己放置（背包里有
  fire 块时右键放置 = 临时营火）。Phase 66 起火会**蔓延**：每 0.1 s
  对**周围 4 邻 + 上方**的可燃块（木/树叶/草/作物，Phase 63）按
  `fire.spread_chance`（默认 5%）roll 引燃（**不向下**烧），所以一片
  干柴旁的火会烧起来——想控火先清可燃物或浇水。**站在火里会被烧**
  **点燃你**（Phase 74：火块 = 熔岩同款点燃——每 0.2 s 掉 1 HP = 5
  HP/s，**离开火堆后还继续烧 8 秒**，进水立刻灭；Phase 70 的
  "站着掉血、离开即停"直伤版已退役），控火时别站在火堆里；**动物和
  怪物同样会被火点燃**（Phase 73：走过火块 = 燃烧，规则与玩家/与
  熔岩完全一致）。火还冒**上升的余烬火星**（`fire.particles`，默认
  开），燃尽/浇灭时"噗"地散一把。
- **火把（torch，Phase 65）**：煤 + 木棍合成的**光 14 光源**（夜里看得见，
  亮度仅次于火）；可贴在任意实心面，**不燃尽**（无寿命、无浇水灭）、
  hardness 0 瞬破且**掉自己**（可拾取复用）；不引燃相邻可燃块（是光源，
  不是火源）。
- 三者入存档（读档后还在）。


- 昼夜循环：`config.json` 的 `world.day_length_seconds`（默认 1200s = 20 分钟
  一天）；`--time 0.25` = 正午、`0.5` = 日落、`0.75` = 午夜。
- **zombie**：只在黑暗生成（开阔地 = 夜晚；树冠/洞穴的暗格白天也危险），
  16 块内发现你就全速追，贴身后每 1 秒打 3 点（随难度缩放：easy 1.5 /
  normal 3 / hard 4）。
- **skeleton**（Phase 27）：同样只在黑暗生成；16 块内发现你，**14 块内开始
  射箭**（每 1.5 秒一支，每支 2 点，随难度缩放），你靠到 3 块内它会边退
  边射——保持中距离对射或绕开它；它的箭有重力弧线（发射时已做提前量
  补偿，站桩躲不掉，**移动可以躲**）。
- **spider**（Phase 46）：只在黑暗生成，比 zombie 快（speed 1.0），贴身
  每 1 秒打 2 点（随难度缩放），**被它近战命中会施加 15 秒中毒**（见
  「状态效果」）——中毒期间血会持续掉，喝牛奶解除；它不掉东西。
- **难度**（`config.json` 的 `mobs.difficulty`）：`easy` / `normal` /
  `hard`——影响敌对生成保护环半径（8/12/16）、敌对伤害（×0.5/1.0/1.33）、

- mob 生成在你周围 4–6 块的环内，同时最多 4 只，离你 40 块外自动消失；
  mob 不入存档（读档后重新自然生成）。

## 营火（campfire，Phase 71）

- **营火（campfire）**：`3 木棍 + 5 木头 + 1 煤炭`（3×3 摆成
  上排棍、中排木-煤-木、下排木）合成的**光 15 篝火**——比火把还亮的光
  源，也是**烤食物的地方**。hardness 0.5，破坏后**掉自己**（捡回来还能
  用）。
- **烤食物**：手持**生肉（牛肉/羊肉/鸡肉）**对准营火**右键** = 放上 1 个
  开始烤（火上面的物品会**悬浮显示**）；营火有 **4 个烤位**（一次能烤 4
  样，每个位各自计时），烤制速度与炉子相同（牛肉 10 秒），**不需要燃料**
  （营火自己一直烧着）。烤好后**空手右键** = 取回（取第一个有的）；没烤完
  也可以空手取回生肉（该位进度作废）。**水浇会灭掉营火的火**（变成没点燃
  的柴堆——上面的食物还在，空手照样能取回，但不再烤）；**拿着燧石与钢
  右键柴堆 = 重新点燃**（MC 同款，烤到一半的进度接着烤）。
- **座位**：站在营火里（点燃的或灭了的都行）**按住左 Ctrl（下蹲）** =
  坐下——坐着不动、跳不了；松开 Ctrl 就站起来。
- 营火（含 4 个烤位里烤到一半的食物和各自的进度）入存档，读档后继续烤。

## 楼梯（stone_stairs，Phase 87）

工作台用 `6 个石头`（台阶形 S/SS/SSS）合成 **4 个石楼梯**。楼梯 = **可以爬
上去的斜面**。4 个朝向块（**朝北/朝东/朝南/朝西**石楼梯，各一个合成配方）
——选哪个放哪个（斜面方向不同）；站在楼梯上，脚的高度随你站的位置变化（越
靠斜面低端越低）。项目用 4 个朝向块表达朝向（不存 per-block 旋转状态）。

## 台阶（stone_slab，Phase 85）

工作台 `3 个石头`（横排一行）合成 **6 个石台阶**。台阶 = **半高的石头**：
放在地上是一个矮石台，**站在它上面**（脚踩在台阶顶面）。v1 只有底部台阶
（没有"上半格"的台阶、没有两个叠成整块、没有斜向楼梯）。

## 熔岩湖（Phase 86）

世界固定位置有**几处熔岩湖**（出生点后方偏右，往 +X/+Z 方向走一段即可看
到）——一圈凹陷里注满熔岩。熔岩会**烧**（踩进去/掉进去持续受伤，MC 同款），
但湖是静态的（不流动、不蔓延）。注意别掉进去（熔岩伤害 4 HP/s）。

## 信标（Phase 83）

信标 = **第二吸收来源**（金苹果之外）。
- **做法**：① 工作台 `9 个铁锭`（3×3 格）合成 1 个**铁块**（MC 同款）。
  ② 在 3×3（或 5×5/7×7/9×9）的**铁块基座**正上方放一个**信标**。
  ③ 站在信标 **50 格内** → 获得**吸收层**（橙色护甲，池 +4）。
- **基座越高越强**：完整 3×3/5×5/7×7/9×9 层 = 等级 1/2/3/4（缺角的层
  只算到最低完整层；**无基座 = 无效果**）。等级越高光束越长。
- **光束**：信标发射一道**半透明青色光束**到天空（`beacon.beam` 关则无光
  束）。**光束不照亮周围**（MC 会；项目文档化偏离），信标块本身不发光。
- 信标 + 铁块**不入世界生成**（只经放置/合成），**入存档**（块编辑，读档
  重建；功率等级每帧从基座重算、无独立状态）。
- **效果词汇表（Phase 84）**：信标机制本身通用——`beacon_effect` 指向哪个
  效果就施加哪个。除吸收外，状态效果系统现还有**速度**（移动 +20%）、**力
  量**（近战 +2）、**抗性**（受伤 −20%）（MC 信标的其它主效果）。shipped
  信标仍施加吸收；想换效果改 `beacon_effect` 数据即可（无附魔台 = 信标只
  施加单一效果，MC 的"主 + 副双效果"无）。
