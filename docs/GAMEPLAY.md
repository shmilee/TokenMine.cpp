## 操作

| 按键 | 功能 |
|---|---|
| `W/A/S/D` | 移动（地面/空中带惯性：松键会滑一小段、空中转向比地面慢一点） |
| 鼠标左键（单击） | 锁定指针——**锁定后才能用鼠标转向视角** |
| 鼠标移动 | 转向视角（仅指针锁定时生效） |
| 鼠标左键（按住） | 挖掘准星处的方块（`1.5s × 方块硬度 ÷ 工具速度`）；若准星对准 mob = 攻击（每 0.25s 一击） |
| 鼠标右键 | 按选中物品：放置方块 / 吃东西 / 拉弓蓄力（松手射出）/ 打开炉子或工作台面板 / 挤奶 / 桶舀倒 / 燧石与钢点火 / 染料染羊毛 / 空手取回营火食物 |
| `Space` | 跳跃（贴地时）；水中 = 上浮 |
| `LeftShift` | 冲刺（5.6 块/秒，行走 4.3；冲刺饥饿衰减 ×2；流体中不能冲刺） |
| `LeftControl` | 潜行（身位降低、变慢、不自动迈 1 格台阶、防跌落边缘） |
| 潜行 + 右键 | 原地旋转楼梯朝向（Phase 92，见「楼梯」） |
| `Tab` | 循环切换热栏选中格 |
| `1`–`9` | 直接选热栏第 1–9 格（CRAFT-7；面板开着时也能用） |
| `Q` | 丢弃选中格物品（落地为掉落物） |
| `E` | 打开背包 + 合成面板（2×2 合成格 + shapeless 配方列表） |
| `F3` | 调试信息（坐标/朝向/时间/难度/FPS + 手持耐久 + 效果档位 + 死亡/击杀统计行） |
| `F5` | 立即存档（仅 `--save` 运行时有效；游戏平时还会自动存档，见「存档」） |
| `R` | 死亡后重生 |
| `ESC` | 解锁指针（面板开着时先关面板）/ 关闭窗口退出 |

**面板内交互**（背包 / 炉子 / 工作台三个面板通用，CRAFT-7 + PRE-12）：

- 左键：取整堆 / 放入 / 交换（既有语义）；左键点面板外 = 丢弃手里拿着的堆。
- **右键取半堆**：空手右键一个占位格 = 取走 `floor(N/2)`（最少 1 个：N=1 取自身、
  N=64 取 32）；耐久随堆走。
- **Shift 快捷移动**（左右 Shift 皆可）：点热栏/主背包格 = 互移（同物同耐久自动
  合并、堆可跨格分裂）；点炉子/工作台容器格 = 移到主背包。
- **双击收集**：双击某格 = 把该分区内所有同物同耐久的堆收集进来（溢出按序回填）；
  热栏（0-8）与主背包（9-26）是两个独立分区。
- **悬停 tooltip**：鼠标停在格子上显示物品名（堆叠显示 `name xN`），工具类第二行
  显示耐久 `已损/最大`。
- 无拖拽（文档化偏离：三键操作 + 数字键已覆盖核心操作面）。

**中文界面**（PRE-1）：死亡屏（"你死了！/ 按 R 重生"）、背包/工作台/炉子面板标题、
"按 E 关闭" 等 UI 文本是中文；F3 调试屏保持英文（开发者工具）；物品/方块名仍是
英文 id（内容数据）。

## 生存循环

1. **白天是安全的**（敌对 mob 只在光照 ≤7 处生成——白天露天 15 = 不生成；树冠/
   洞穴的暗格里白天也会生成）。挖树（`wood`）→ 合成木板/木棍/工具（见下）；
   挖矿石获得材料（煤/铁/金/钻石/青金石直接掉对应材料）。
2. **天黑前做好准备**：夜里 zombie（贴身近战）和 skeleton（远距离射箭）会
   生成并追杀你。**深夜露天不是全黑**——有 MC 同款月光（光级 7/15，LGT-3），
   你看得清周围，但那恰好是敌对生成门槛 = 露天夜里照样危险；火把（光 14）
   照得到的地方不生成敌对。世界出生点周围有保护环（按难度 8/12/16 块），
   敌对 mob 不会在环内自然生成。想要绝对安全：`config.json` 的
   `mobs.difficulty` 设 `peaceful`（见「昼夜、难度与 Mob」）。
3. **饥饿**：饥饿值 20，每 36 秒自然衰减 1 点（**疾跑**（`LeftShift` + 移动）
   时 ×2 = 每 18 秒）；衰减先消耗隐藏的**饱和度**缓冲，缓冲耗尽才掉饥饿条
   （"吃饱了饿得慢"）。饱和度按食物定（SURV-9）：**熟肉远比生肉顶饿**——
   熟牛排 12.8 vs 生牛肉 1.8（见下「食物全表」）；所以**肉最好先烤熟再吃**。
4. **回复生命**：脱离受伤 10 秒后，若饥饿 ≥ 6，每 4 秒自动回 1 HP——
   **每次回复消耗 1 点饥饿**（先扣饱和缓冲，SURV-9；满血时流逝不扣）。
5. **护甲**（SURV-1/3）：12 件（皮/铁/钻 × 头盔/胸甲/护腿/靴子），每 1 点
   护甲减伤 4%（皮套 28% / 铁套 56% / 钻套 80%）。手持护甲右键 = 穿到对应
   部位（穿满的会先脱下来换）；心行上方出现护甲排。护甲**会磨损**：每次
   实际减伤事件，身上每件 −1 起（重击多扣），扣完破碎（见「耐久」）。
6. **水下氧气**（SURV-2）：头没入水/熔岩时 15 秒一口气——心行下方换成
   **气泡排**（10 泡）；耗尽后每 2.5 秒掉 2 HP（能淹死，护甲挡不住）。
   眼睛露出水面（如浅池踩水）= 换气，气泡回满。
7. **工具会坏**（SURV-3）：全部工具/弓/燧石与钢/护甲有耐久，会随使用磨损、
   扣完破碎消失——**没有修复系统**（无铁砧/磨刀石/合成修复，文档化偏离）。
   详见「耐久」。
8. **死亡**：HP 归零 → 画面冻结显示 "你死了！/ 按 R 重生"，按 `R` 回出生点
   重生（满血 + 满饥饿 + 满饱和度，**背包保留**）。坠落（净下落 > 3 格）和掉出
   世界（y < −32）都会致命。你的**死亡次数和每种 mob 的击杀数**被记录，
   F3 统计行可见（`stats deathCount N | kill.zombie N …`，SURV-7）。

## 战斗与食物

- **攻击**：左键按住挥击，伤害 = **选中物品**的 `attack_damage`（徒手/方块/
  材料 = 1，木镐 = 2，铁镐 = 3，弓近战 = 1），命中 mob 还会击退它。
  带**虚弱**效果时近战伤害相应降低（虚弱的徒手打出 0 伤害）。用镐/斧/铲
  打 mob 会额外磨损工具（耐久 −2/击）。
- **杀 mob 掉物品**（走近掉落物自动拾取，0.5s 拾取延迟；每只 mob 的数据可定义
  **多个掉落**，死亡时按列表顺序各掉一件）：

  | mob | HP | 掉落 | 备注 |
  |---|---|---|---|
  | zombie（夜晚/黑暗） | 20 | `rotten_flesh` ×1 | **食物**；不死族（免疫毒） |
  | skeleton（夜晚/黑暗） | 20 | `bone` 0–2 + `arrow` ×1 | 箭带**枯萎**效果（见下）；不死族 |
  | spider（夜晚/黑暗） | 16 | 无 | 近战命中上 15 s 毒 |
  | cow（任意光照） | 10 | `leather` + `beef` | 材料 + **食物**；可挤奶 |
  | sheep（任意光照） | 8 | `wool` + `mutton` | 材料 + **食物** |
  | chicken（任意光照） | 4 | `feather` + `chicken` | 材料 + **食物** |

- **箭**（skeleton 掉落 / 燧石+木棍+羽毛 合成）：插在方块上的箭**走近即拾取**
  （1.0 块内，返还 1 支箭；飞行中的箭拾不了）；箭插着的**方块被破坏时箭会掉
  下来**（落地后可拾取）；插墙箭停留 100 秒后消散。箭命中的击退**随拉弓蓄
  力**变化——拉得越满击退越强（满蓄力 = 最强）。
  - **skeleton 的箭带枯萎**（SURV-5）：命中你 = 10 秒枯萎（每 4 秒掉 1 HP，
    **没有地板——能把你打死**）；被箭射中的 mob 也会中枯萎。
  - **毒弓（poison_bow）**：`弓 + 中毒药水` 工作台合成（shapeless）——射出的箭
    带 60 秒中毒（每 2.5 秒 1 HP，你还有 1 HP 地板，但 **mob 能毒死**）。
  - **僵尸/骷髅（不死族）免疫毒**（MC 同款）。
- **吃东西**：选中食物后**按住右键 1.6 秒** = 吃（3D 手部随进度抬向面部；
  **中途松开 = 取消不吃**，受击/死亡/解锁鼠标/开面板/换物品/左键挥击同样
  取消且**不消耗食物**；完成时回复该食物的饥饿 + 饱和度、消耗 1 个、播放
  进食音）。满饥饿时右键食物 = 无效果（仍吞掉该次右键）。
- **食物全表**（10 种；饥饿 = 直接回复，饱和 = 缓冲充入，SURV-9 全 MC 值）：

  | 食物 | 饥饿 | 饱和度 | 来源 |
  |---|---|---|---|
  | 腐肉 `rotten_flesh` | 4 | **0.8** | zombie |
  | 生牛肉 `beef` | 3 | **1.8** | cow |
  | 生羊肉 `mutton` | 2 | **1.2** | sheep |
  | 生鸡肉 `chicken` | 2 | **1.2** | chicken |
  | **熟牛肉** `cooked_beef` | 8 | **12.8** | 炉子/营火烤 |
  | **熟羊肉** `cooked_mutton` | 6 | **7.2** | 炉子/营火烤 |
  | **熟鸡肉** `cooked_chicken` | 6 | **7.2** | 炉子/营火烤 |
  | 面包 `bread` | 5 | 6.0 | 3 小麦合成 |
  | 苹果 `apple` | 4 | 2.4 | 树叶 1/128 概率掉 |
  | 金苹果 `golden_apple` | 4 | 9.0 | 8 金锭镶 1 苹果 |

  一眼规律：**生肉给得少还顶不饿（低饱和），熟肉饱和度是它们的 6–7 倍**
  ——烤熟再吃。
  所以生存闭环是：**打/杀 mob → 烤熟掉落肉 → 撑过夜晚**（被动 mob 也是食物
  来源；面包/苹果是稳定食物线）。
- **mob 行为**（v1.x 补强）：
  - 走路时**四肢摆动**（鸡 2 腿、牛羊 4 腿对角步态、蜘蛛 8 腿——纯视觉；
    僵尸/骷髅没有独立的四肢部件，不摆，记档）。
  - 会**踏 1 格台阶**（slab/满块都能上），追你会**绕障碍物寻路**（不卡墙）。
  - 会**涉水游泳**（流体中减速 0.6×，能踩 1 格岸壁自己爬出浅池；夜里水里
    的 zombie 会游向你）。
  - **会坠落死**（净落差 > 3 格，和你同款规则）——高台边的 mob 掉下去可能
    白给。
  - **燃烧时冒上升的火星**、自身发光（深夜也看得清它在烧）。

## 工具与合成路线

- **E 面板**（2×2 格 + 左侧 shapeless 配方列表，点配方直接合成）：
  - `wood` → 木板 ×4；木板 ×2 → 木棍 ×4；木板 2×2 → 工作台
  - 燧石 + 木棍 + 羽毛 → 箭 ×4（Phase 60，MC 1.14+；羽毛 = 杀鸡掉落）
  - 煤 + 木棍 → 火把 ×4（Phase 65，MC；煤 = 煤矿石掉落）
  - 燧石 + 铁锭 → 燧石与钢（Phase 60）
  - 锻石 ×4 → 石头（Phase 61，MC 材料循环）
  - 泥土 ×1 → 耕地（Phase 50）
- **工作台**（右键放置的方块，3×3 格）：
  - **每块工作台独立**（CRAFT-1）：你放的每块工作台有**自己的** 3×3 网格和
    内容物，互不同步（旧版全游戏共享一格已修复）；**破坏工作台会把里面没取
    走的物品一起掉出来**。
  - **面板显示全部 shaped 配方提示**（CRAFT-4）：右侧两列 = 所有 shaped
    配方，每行是摆放图案 + 输出；**你能供上料的行高亮、供不上的变暗**
    （点击提示行不会合成，只是看配方）。
  - 木镐（木板 3 + 木棍 2，镐形）——挖掘速度 ×2（**石类/矿类 ×2 = ×4**，
    Phase 69）、攻击 2
  - 石镐（锻石 3 + 木棍 2，镐形）——挖掘速度 ×3（石类/矿类 ×2 = ×6）、
    攻击 2.5（Phase 62，镐路线中档；锻石 = 挖天然石头掉落）
  - 铁镐（铁锭 3 + 木棍 2）——挖掘速度 ×4（石类/矿类 ×2 = ×8）、攻击 3
    （铁锭 = 挖铁矿石）
  - 木斧（木板 2 + 木棍 2，L 形）——对**木头/树叶 ×2**（其它块 = 手速）、攻击 3（Phase 67）
  - 石斧（锻石 2 + 木棍 2）——同上、攻击 3.5（锻石 = 第二个工具用途）
  - 铁斧（铁锭 2 + 木棍 2）——同上、攻击 4
  - 木铲（木板 1 + 木棍 2，竖列）——对**泥土/草/沙/砂砾 ×2**（其它块 = 手速）、攻击 2.5（Phase 68）
  - 石铲（锻石 1 + 木棍 2）——同上、攻击 3（锻石 = 第三个工具用途）
  - 铁铲（铁锭 1 + 木棍 2）——同上、攻击 3.5
  - 弓（木棍 3 + 木板 1，C 形）；6 石头（台阶形）→ 石楼梯 ×4；
    3 石头横排 → 台阶 ×6；6 石头（无序）→ 墙 ×4；4 木板 + 2 木棍 → 栅栏 ×3；
    8 玻璃（无序）→ 玻璃板 ×16；9 铁锭（3×3）→ 铁块
  - 护甲：皮（leather = 杀牛）/ 铁（铁锭）/ 钻（钻石）各 4 件，MC 摆法
    （头盔 3 排 / 胸甲 5 / 护腿 5 / 靴子 4）
  - 砂岩（沙 3 → 1，Phase 80）、光滑砂岩（砂岩 2 → 1，Phase 81）
  - 各种强化弓（见下）、毒弓（弓 + 中毒药水）、金苹果（8 金锭镶 1 苹果）
- **分块效率（MC 规则）**：镐 = 石/锻石/五种矿石（煤/铁/金/钻石/青金石）/
  萤石/砂岩/光滑砂岩 ×2；斧 = 木头/树叶 ×2；铲 = 泥土/草/沙/砂砾 ×2。
- **错工具慢 10×**（SURV-8）：工具用它不擅长的块 = 速度 ×0.1（MC 同款惩罚）——
  铁镐挖木头 7.5 s（徒手才 3 s）、铁斧挖石头比徒手还慢。手（非工具）不受
  影响。
- **石头→锻石循环**（Phase 61，Minecraft 同款）：挖**天然石头**掉
  **锻石（cobblestone）**；锻石 ×4 合成回石头（不能熔炼回 = 见
  KNOWN_ISSUES 的文档化偏离）。
- **砂岩链**（Phase 80/81）：`沙 → 砂岩 → 光滑砂岩` 单向（3 沙 → 1 / 2 砂岩
  → 1），无锻回；砂岩/光滑砂岩都是镐的 ×2 家族（手挖 2.25 s、铁镐 0.28 s），
  破坏掉自己。
- **弓 5 种 + 毒弓**：
  - **弓**：选中**按住右键**拉弓（1.6s 满蓄力），**松手射出**——伤害/速度 =
    5 × 威力 / 15 × 威力（快速点射 = 最低威力 0.1）；每支箭消耗 1 个 `arrow`
    弹药（没有箭射不出去）；左键 = 弓近战（伤害 1，永不挖掘）。
  - **无限弓（infinite_bow，Phase 77）**：`弓 + 钻石` 合成 1 个（MC Infinity
    附魔的可合成替身）——**射箭不耗弹药**：只要持有 ≥1 支箭就能无限射。
  - **力量弓 / 速度弓（Phase 79）**：`弓 + 2 钻石` → 力量弓（箭伤害 5 → 8）；
    `弓 + 金锭` → 速度弓（箭初速 15 → 20，飞得更远更快）。
  - **大师弓（master_bow，Phase 82）**：`力量弓 + 速度弓 + 无限弓` 合成 1 个
    ——三项全叠的顶点弓（伤害 8、初速 20、不耗箭）。
  - **毒弓（poison_bow，SURV-5）**：`弓 + 中毒药水` 合成 1 个——箭带 60 s 中毒
    （见「战斗与食物」）。
  - 弓每射一箭磨损 1 点耐久（无限弓同样磨损）。
- **护甲（SURV-1）**：
  - 12 件，MC 精确值：**皮套 7 点（28% 减伤）/ 铁套 14 点（56%）/ 钻套
    20 点（80%）**——减伤 = 4% × 总点数（最终伤害向下取整）；溺水/中毒等
    bypass 类伤害护甲挡不住。
  - 穿戴：**手持护甲右键** = 穿上（该部位已穿 = 新旧交换，旧的回选中槽）；
    脱整套要每件之间换空热栏槽（热栏只有 Tab/数字键循环，无拖拽）。
  - 心行上方出现**护甲排**（仅占位槽显示）；每件护甲有耐久（皮 55/80/75/65、

## 水/熔岩/蜂蜜桶（Phase 47，Phase 51 熔岩，FLUID-4/5/6）

- **舀水/熔岩/蜂蜜**：手持**空桶**右键**流体表面**（必须是"源头"——静止
  的一整格；流动的膜舀不到）= 流体被收进桶里，空桶变**水桶/熔岩桶/蜂蜜
  桶**（"splash" 音效）。一个空桶三种都舀（MC 语义）。隔着一堵墙/流动膜
  舀不到（准星先打到别的东西）。
- **倒水/熔岩/蜂蜜**：手持**满桶**右键**方块表面**（空地、不踩着自己）=
  倒出一格源头流体，满桶变回空桶。倒出的流体随后正常流动/扩散——倒在
  半空中它会落下来，倒在平地它会摊开。
- **倒向流动水面**（FLUID-4）：满桶对准**流动的膜**（非源头水）= 那一格
  **变源**（水不再流走，MC 同款"对着流水倒桶"）。对已源水/异种流体 =
  不发生（桶保留）。
- **桶 × 反应**（FLUID-5）：**水桶对准熔岩格** = 在受击面方向那格干空气
  放一源水，随即与熔岩反应成**黑曜石**（倒出的恒为源水）；没有空位
  可放 = 不发生（桶保留）。**熔岩桶对准水格** = 该格被熔岩源替换，随
  即与周围残留的水反应（源水 → 黑曜石、流动水 → 石头）。
- **水 + 熔岩 = 石头/黑曜石**（MC 同款，既有规则）：熔岩**挨着水**时反应
  ——挨着的是**源头水** → 黑曜石；挨着的是**流动水** → 石头。水不被消耗。
  熔岩会**发光**（夜里也能照出熔岩池）。
- **蜂蜜**（FLUID-6，MC 1.14+ 第三流体）：一种**黏稠流体，流动速度只有
  水的 1/3**（摊开/下坠都慢 3 倍），不引燃、不反应。来源 = **初始储物的
  蜂蜜桶**（1 个，桶是唯一获取途径——世界无蜂箱，记档偏离）；倒出后可
  再用空桶舀回。
- 桶**不能喝**（右键只舀/倒），桶永远不放方块。背包满时舀/倒不发生
  （点击被吞）。流体入存档（读档后你倒的水/熔岩/蜂蜜还在）。
- 熔岩**会烧**（Phase 54）：站在熔岩格里**每秒受 4 HP 灼烧伤害**
  （Minecraft 速率，走正常伤害路径 = 红闪/音效/死亡全触发）；熔岩里移动
  比水里**明显更慢**（横移/上浮/下沉都是熔岩节奏）；掉进熔岩**取消坠落
  伤害**（与水同款）。碰熔岩还会**点燃**你（Phase 57 火系统，见上
  「燃烧」）：熔岩内直接灼烧 + 燃烧效果叠加（~9 HP/s，Minecraft 同款），
  **离开熔岩后继续烧 8 秒**，进水立刻熄灭。
- 熔岩**也烧 Mob 和可燃方块**（Phase 58）：Mob 踏入/接触熔岩即被
  **点燃**（每 0.2 秒掉 1 HP，与玩家同款节奏，能烧死；离熔岩继续
  烧 8 秒，进水熄灭）；可燃方块（作物小麦 7 阶 + 木头/树叶/草方块，
  Phase 63 = MC 天然可燃面）被熔岩 6-邻接触**烧成空**（无掉落）。
  水不烧任何东西。

  掉 1 个**燧石（flint）**（Minecraft 同款概率）。概率是**确定性**的——
  同一格每次破坏结果相同（破坏-重放-再破坏不变），多挖总能攒到。
- **燧石（flint）**：两个用途（Phase 60，Minecraft 主用途）：**箭配方**
  （燧石 + 木棍 + 羽毛 → 箭 ×4）与**燧石与钢**（燧石 + 铁锭）；
  64 个一叠。
- 两者入存档（读档后还在）。

## 燧石与钢、火、火把（Phase 60/63/64/65/66/73/74）

- **燧石与钢**（耐久 64，每次点火 −1）：选中后**右键可燃块**
  （作物 wheat_1..7 + 木头/树叶/草方块/树苗，Phase 63 = MC 天然可燃面）
  = 该块**烧成火（fire）**、无掉落（与熔岩烧同款语义）；**右键未点燃

  仍正常开面板。
- **火（fire，Phase 64；Phase 66 粒子 + 蔓延）**：可燃块被点燃器或熔岩
  烧掉后**留下的火焰块**——**光 15 的光源**（夜里看得见），几秒后
  **自己燃尽**（`fire.lifetime_seconds`，默认 4 秒），**浇水立刻灭**
  （6 邻有水即灭）；破坏/燃尽都不掉东西。Phase 66 起火会**蔓延**：每
  0.1 s 对**周围 4 邻 + 上方**的可燃块按 `fire.spread_chance`（默认 5%）
  roll 引燃（**不向下**烧），所以一片干柴旁的火会烧起来——想控火先清
  可燃物或浇水。**站在火里会点燃你**（Phase 74：火块 = 熔岩同款点燃
  ——每 0.2 s 掉 1 HP = 5 HP/s，**离开火堆后还继续烧 8 秒**，进水立刻
  灭），控火时别站在火堆里；**动物和怪物同样会被火点燃**（Phase 73：
  走过火块 = 燃烧，规则与玩家/与熔岩完全一致；燃烧的 mob 冒上升火星、
  自身发光，PRE-8）。火还冒**上升的余烬火星**（`fire.particles`，默认
  开），燃尽/浇灭时"噗"地散一把。
- **火把（torch，Phase 65）**：煤 + 木棍合成的**光 14 光源**（夜里看得见，
  亮度仅次于火）；可贴在任意实心面，**不燃尽**（无寿命、无浇水灭）、
  hardness 0 瞬破且**掉自己**（可拾取复用）；不引燃相邻可燃块（是光源，
  不是火源）。**火把照得到的地方（光 14）不生成敌对 mob**——夜间防御
  的核心手段。
- 火/火把入存档（读档后还在）。

## 昼夜、难度与 Mob（Phase 23/27/46；LGT-3 月光；ENT-8 和平）

- 昼夜循环：`config.json` 的 `world.day_length_seconds`——**当前配置 =
  600 s = 10 分钟一天**（代码默认 240 s）；新开世界从正午开始（0.25）。
  `--time 0.25` = 正午、`0.5` = 日落、`0.75` = 午夜。
- **深夜有月光**（LGT-3，MC 同款）：露天夜里光级 = 7/15（不是全黑），
  看得清环境——但 7 正好是敌对生成门槛，**露天夜晚照样危险**；树冠下
  更暗（树叶有光衰减，LGT-2）。
- **难度**（`config.json` 的 `mobs.difficulty`，当前配置无覆盖 = 代码
  默认 `normal`）：
  - `easy` / `normal` / `hard`：保护环 8/12/16 块、敌对伤害 ×0.5/1.0/
    ×1.33、敌对生成节奏慢/中/快。
  - **`peaceful`（ENT-8）**：**全世界零敌对生成**（被动动物照生）=
    没有怪物伤害的休闲模式。
- **zombie**：只在光照 ≤7 处生成（开阔地 = 夜晚；树冠/洞穴的暗格白天
  也危险），16 块内发现你就全速追，贴身后每 1 秒打 3 点（随难度缩放：
  easy 1.5 / normal 3 / hard 4）。
- **skeleton**（Phase 27）：同样只在光照 ≤7 处生成；16 块内发现你，
  **14 块内开始射箭**（每 1.5 秒一支，每支 2 点 + **10 秒枯萎**，随难度
  缩放），你靠到 3 块内它会边退边射——保持中距离对射或绕开它；它的箭
  有重力弧线（发射时已做提前量补偿，站桩躲不掉，**移动可以躲**）。
- **spider**（Phase 46）：只在光照 ≤7 处生成，比 zombie 快（speed 1.0），
  贴身每 1 秒打 2 点（随难度缩放），**被它近战命中会施加 15 秒中毒**
  （见「状态效果」）——中毒期间血会持续掉，喝牛奶解除；它不掉东西。
- mob 生成在你周围 4–6 块的环内，同时最多 4 只，离你 40 块外自动消失；
  敌对需要光照 ≤7、被动（牛/羊/鸡）任意光照；mob 不入存档（读档后重新
  自然生成）。

## 营火（campfire，Phase 71；P75-78 四槽/浇灭/再点燃/全图标）

- **营火（campfire）**：`3 木棍 + 5 木头 + 1 煤炭`（3×3 摆成
  上排棍、中排木-煤-木、下排木）合成的**光 15 篝火**——比火把还亮的光
  源，也是**烤食物的地方**。hardness 0.5，破坏后**掉自己**（捡回来还能
  用）。
- **烤食物**：手持**生肉（牛肉/羊肉/鸡肉）**对准营火**右键** = 放上 1 个
  开始烤；营火有 **4 个烤位**（一次能烤 4 样，每个位各自计时，4 个烤位
  的物品图标都悬浮显示），烤制速度与炉子相同（牛肉 10 秒），**不需要
  燃料**（营火自己一直烧着）。烤好后**空手右键** = 取回（取第一个有的）；
  没烤完也可以空手取回生肉（该位进度作废）。
- **水浇会灭掉营火的火**（变成没点燃的柴堆——上面的食物还在，空手照样
  能取回，但不再烤）；**拿着燧石与钢右键柴堆 = 重新点燃**（MC 同款，
  烤到一半的进度接着烤）。
- **座位**：站在营火里（点燃的或灭了的都行）**按住左 Ctrl（下蹲）** =
  坐下——坐着不动、跳不了；松开 Ctrl 就站起来。
- 营火（含 4 个烤位里烤到一半的食物和各自的进度）入存档，读档后继续烤。

## 楼梯（stone_stairs，Phase 87/89/92/97）

## 墙（stone_wall，Phase 95/96）

## 玻璃板（glass_pane，Phase 99）

1.0**（比墙矮）

## 信标（beacon，Phase 83；P91 双效果；LGT-4 光束昼夜）

信标 = **持续效果来源**（金苹果之外）。
- **做法**：① 工作台 `9 个铁锭`（3×3 格）合成 1 个**铁块**（MC 同款）。
  ② 在 3×3（或 5×5/7×7/9×9）的**铁块基座**正上方放一个**信标**。
  ③ 站在信标 **50 格内** → 同时获得**吸收层（4 点红心池）+ 速度
  （移动 1.2×）**（P91：MC 主 + 副双效果）。
- **基座越高越强**：完整 3×3/5×5/7×7/9×9 层 = 等级 1/2/3/4（缺角的层
  只算到最低完整层；**无基座 = 无效果**）；等级 4 光束最长。
- **光束**：信标发射一道**半透明青色光束**到天空（`beacon.beam` 关则无
  光束）；**光束颜色随昼夜变**（深夜月光下变暗，LGT-4）。
  光束不照亮周围（MC 会；项目文档化偏离），信标块本身不发光。
- 信标 + 铁块**不入世界生成**（只经放置/合成），**入存档**（块编辑，
  读档重建；功率等级每帧从基座重算、无独立状态）。

## 存档（SAVE-1/3）

- **自动存档**：`--save` 运行时，**每 2 分钟自动存档一次**（代码默认
  120 s；`config.json` 的 `save.auto_save_seconds` 可改，0 = 关闭；
  当前配置无覆盖 = 默认 2 分钟）。
- **手动**：`F5` 立即存档（`--save` 运行时）；**退出时自动存档**。
- **槽位管理**（headless CLI，不启动游戏，SAVE-3）：
  `--list-saves`（列出所有槽 + 摘要：种子/昼夜时/位置/血量）、
  `--copy-save 源 目标`（字节保真复制）、`--rename-save 源 目标`（重命名）、
  `--delete-save 槽名`（删除）。槽名 = 字母/数字/`_`/`-`；每跑至多一个
  管理命令，与游戏参数互斥。多存档 = 多个槽（游戏内选档面板未实现 =
  记档偏离）。
