## 操作

| 按键 | 功能 |
|---|---|
| `W/A/S/D` | 移动（地面/空中带惯性：松键会滑一小段、空中转向比地面慢一点） |
| 鼠标左键（单击） | 锁定指针——**锁定后才能用鼠标转向视角** |
| 鼠标移动 | 转向视角（仅指针锁定时生效） |
| 鼠标左键（按住） | 挖掘准星处的方块（`1.5s × 方块硬度 ÷ 工具速度`）；若准星对准 mob = 攻击（每 0.25s 一击） |
| 鼠标右键 | 按选中物品：放置方块 / 吃东西 / 拉弓蓄力（松手射出）/ 打开炉子或工作台/附魔台面板 / 挤奶 / 剪羊毛 / 桶舀倒 / 燧石与钢点火 / 染料染羊毛·陶瓦·床 / 染料染羊 / 空手取回营火食物 / 对床睡觉·设重生点 |
| 鼠标滚轮 | 第三人称时缩放相机距离（2–8 块，步进 0.5；第一人称无效，V2-19）；demo 回放中 = 切速度 0.5×/1×/2× |
| `Space` ×2（0.3 s 内） | 开/关**飞行**（MC 创造同款手势：重力关闭，Space 升 / `LeftShift` 降，水平 1.6×；进出水/熔岩自动切出，V2-19） |
| `Space` | 跳跃（贴地时）；水中 = 上浮 |
| `LeftShift` | 冲刺（5.6 块/秒，行走 4.3；冲刺饥饿衰减 ×2；流体中不能冲刺） |
| `LeftControl` | 潜行（身位降低、变慢、不自动迈 1 格台阶、防跌落边缘） |
| 潜行 + 右键 | 原地旋转楼梯朝向（Phase 92，见「楼梯」） |
| `Tab` | 循环切换热栏选中格 |
| `1`–`9` | 直接选热栏第 1–9 格（CRAFT-7；面板开着时也能用） |
| `Q` | 丢弃选中格物品（落地为掉落物） |
| `E` | 打开背包 + 合成面板（**36 格** = 9 热栏 + 27 背包 4 行【UX-8f】+ 2×2 合成格 + **两列** shapeless 配方列表，**能合成的排最前**【UX-8c】） |
| `F3` | 调试信息（坐标/朝向/时间/难度/FPS + 手持耐久 + 效果档位 + 死亡/击杀统计行 + 教程行） |
| `F5` | 立即存档（仅 `--save` 运行时有效；游戏平时还会自动存档，见「存档」） |
| `C` | 切换第一/第三人称相机（第三人称：相机在身后上方 4 块、贴墙自动收敛；**头部在准星下方**（v2.0.0 抬相机，准星不再压头）；**瞄准射线仍从你的眼睛出发**——屏幕正中的射线与眼位射线有固定视差（MC 同款），精确点射/瞄准切回第一人称；仅指针锁定时生效，会话态不入存档——读档回第一人称） |
| `T` | 跳过新手指导（仅指针锁定且教程未结束时；效果等同完成，"全部完成！"提示后不再出现） |
| `R` | 死亡后重生 |
| `ESC` | 解锁指针（面板开着时先关面板）/ 关闭窗口退出；**demo 回放中 = 暂停/继续**（不是退出） |
| `Q`（demo 暂停/结束面板开着时） | 退出 demo 回放 |

**手柄**（`[V3-8]` v3.3.0 起 + `[V3-8b]` v3.14.0 习惯定案；Xbox 标准
布局，连接即生效，F3 末行显示连接态；PlayStation / Switch 手柄经 SDL
归一化 = 同款行为）：
左摇杆 = 移动（对角 = 双方向）/ 右摇杆 = 转视角 / **A** = 跳跃（双击 =
飞行，MC 创造同款手势）/ **B** = **飞行开关**（单击直接起飞/落地 = 专用
钮，v3.14.0 定案）/ **X** = 背包 / **Y** = 丢弃 / **LB** = 挖掘·攻击 /
**RB** = 使用·放置（蓄力弓同松开语义）/ **RT 扳机** = 冲刺（按住）/
**L3**（左摇杆按下）= 蹲伏（按住）/ **Back** = 切相机 / **Start** =
ESC / D-pad 右 = Tab 热栏循环。键鼠手柄可同用（同一动作的并集——任一侧
按住就不松开）；LT / R3 等未映射（记档）。

**面板内交互**（背包 / 炉子 / 工作台三个面板通用，CRAFT-7 + PRE-12）：

- 左键：取整堆 / 放入 / 交换（既有语义）；左键点面板外 = 丢弃手里拿着的堆。
- **右键取半堆**：空手右键一个占位格 = 取走 `floor(N/2)`（最少 1 个：N=1 取自身、
  N=64 取 32）；耐久随堆走。
- **Shift 快捷移动**（左右 Shift 皆可）：点热栏/主背包格 = 互移（同物同耐久自动
  合并、堆可跨格分裂）；点炉子/工作台容器格 = 移到主背包。
- **双击收集**：双击某格 = 把该分区内所有同物同耐久的堆收集进来（溢出按序回填）；
  热栏（0-8）与主背包（9-35）是两个独立分区。
- **悬停 tooltip**：鼠标停在格子上显示物品名（堆叠显示 `name xN`），工具类第二行
  显示耐久 `已损/最大`。
- 无拖拽（文档化偏离：三键操作 + 数字键已覆盖核心操作面）。

**中文界面**（PRE-1）：死亡统计屏（"你死了！/ 死因 / 会话统计 / 按 R 重生"）、背包/工作台/炉子面板标题、
"按 E 关闭" 等 UI 文本是中文；F3 调试屏保持英文（开发者工具）；物品/方块名仍是

开局后热栏上方一行目标指引逐步带路（MC objective 式，**11 步**）：
**按 W 向前走 → 打木头×3 → 合成 4 个木板（1 木头变 4）→ 做 1 个工作台
（4 木板排 2×2）→ 合成木镐 → 挖石头×5 → 合成石镐 → 挖 1 个煤矿石 →
合成 1 个火把（1 煤 + 1 木棍）→ 放 1 个火把 → 打 1 只白色小动物（打

黑乎乎怎么打怪」：煤矿石多在地下洞中，火把光 14 能挡住敌对生成（门槛 7）。
11 步全清 = "全部完成！" 提示后不再出现。

- 进度随存档保存（读档续接；教程内容变更时该步自动重置为首步）。
- 随时按 `T` 跳过。config `tutorial.enabled: false` 可整体关闭（默认开）。
- 只数你实际做的动作（行为事件，不是"背包里有镐"式状态查询——MC 同款）。

## 生存循环

1. **白天是安全的**（敌对 mob 只在光照 ≤7 处生成——白天露天 15 = 不生成；树冠/
   洞穴的暗格里白天也会生成）。挖树（`wood`）→ 合成木板/木棍/工具（见下）；
   挖矿石获得材料（煤/铁/金/钻石/青金石直接掉对应材料；**下界矿见
   「传送门与下界」**：quartz ore 掉 quartz、nether gold ore 掉金锭、
   ancient debris 掉自己 = netherite 链原料）。
2. **天黑前做好准备**：夜里 zombie（贴身近战）和 skeleton（远距离射箭）会
   生成并追杀你。**深夜露天不是全黑**——有 MC 同款月光（光级 7/15，LGT-3），
   你看得清周围，但那恰好是敌对生成门槛 = 露天夜里照样危险；火把（光 14）
   照得到的地方不生成敌对。世界出生点周围有保护环（按难度 8/12/16 块），
   敌对 mob 不会在环内自然生成。想要绝对安全：`config.json` 的
   `mobs.difficulty` 设 `peaceful`（见「昼夜、难度与 Mob」）。
3. **饥饿**：饥饿值 20，每 36 秒自然衰减 1 点（**疾跑**（`LeftShift` + 移动）
   时 ×2 = 每 18 秒）；衰减先消耗隐藏的**饱和度**缓冲，缓冲耗尽才掉饥饿条
   （"吃饱了饿得慢"）。饱和度按食物定（SURV-9）：**熟肉远比生肉顶饿**——
   熟牛排 12.8 vs 生牛肉 1.8（见下「食物全表」）；所以**肉最好先烤熟再吃**。
4. **回复生命**：脱离受伤 10 秒后，若饥饿 ≥ 6，每 4 秒自动回 1 HP——
   **每次回复消耗 1 点饥饿**（先扣饱和缓冲，SURV-9；满血时流逝不扣）。
5. **护甲**（SURV-1/3；V3-4 加下界合金）：**16 件**（皮/铁/钻/下界合金
   × 头盔/胸甲/护腿/靴子），每 1 点护甲减伤 4%（皮套 28% / 铁套 56% /
   钻套 80% / 下界合金套 80%，耐久是钻石的 1.5 倍）。手持护甲右键 = 穿到
   对应部位（穿满的会先脱下来换）；心行上方出现护甲排。护甲**会磨损**：
   每次实际减伤事件，身上每件 −1 起（重击多扣），扣完破碎（见「耐久」）。
   **下界合金护甲 = 火·熔岩免疫**（v3.16.0）：任一件穿在身上，熔岩不烧
   你、火块不点燃你——下界漫步的保命装。
6. **水下氧气**（SURV-2）：头没入水/熔岩时 15 秒一口气——心行下方换成
   **气泡排**（10 泡）；耗尽后每 2.5 秒掉 2 HP（能淹死，护甲挡不住）。
   眼睛露出水面（如浅池踩水）= 换气，气泡回满。
7. **工具会坏，但能修**（SURV-3 + UX-5）：全部工具/弓/燧石与钢/护甲有
   耐久，会随使用磨损、扣完破碎消失。**修复**：工作台把受损工具和 1 个
   对应材料放一起（铁系+铁锭/石系+锻石/木系+木板/弓+木棍/燧石与钢+燧石/
   皮甲+皮/钻甲+钻）→ 输出槽 = 修好的它（1 材料回 25% 最大耐久），点一下
   取走；E 面板 2×2 也能修。没有 XP 成本/越修越贵（记档偏离：MC 铁砧有
   XP 成本，项目工作台修复零成本——XP 系统见「经验值与附魔」）。详见
   「耐久」。
8. **死亡**：HP 归零 → 画面冻结显示**死亡统计屏**（v3.15.0）——「你
   死了！」+ **死因**（「被 zombie 杀死」/「死于高处掉落」/「饿死」
   …）+ 本次会话统计（采挖/放置/击杀/行走/存活时长）+「按 R 重生」，
   按 `R` 回**重生点**重生（= 睡过的床【床被破坏/堵死则回退】，没睡过
   床 = 世界出生点；满血 + 满饥饿 + 满饱和度，**背包保留**。**在下界
   死亡 = 回主世界重生**——重生点永远在主世界，见「传送门与下界」）。
   坠落（净下落 > 3 格）和掉出世界（y < −32）都会致命。你的**死亡次数
   和每种 mob 的击杀数**持久记录，F3 统计行可见（`stats deathCount N
   | kill.zombie N …`，SURV-7；死亡屏的采挖/放置/行走统计 = 本次会话
   级，随进程重置）。
9. **创造模式**（`V3-11a/b`，v3.17.0/v3.18.0）：准星锁定下按 `G`
   切换创造/生存——**模式随存档保存**（关重开仍是创造；装载时自动
   进入飞行）。创造下：**不会死**（熔岩/坠落/mob/箭/饥饿等一切伤害
   源全部免疫）、**饥饿条恒定满**、**即挖**（左键一下破块）、
   **挖掘不掉落、不掉经验、不磨工具**（破碎粒子与音效保留）、
   **放置不消耗物品**、进入即**飞行**（双击 `Space` 回行走）。
   **创造物品栏（`V3-11b`）**：创造下按 `E` 开的面板顶部有「物品
   栏/背包」两个 tab——**物品栏**里直接打字即可**前缀搜索**全部
   224 种物品（a-z 0-9 _，滚轮翻页），**左键点击 = 给满一组到选中
   热栏位**、**右键 = 给 1 个**（同物合并、异物替换）；**背包** tab
   = 原来的背包/合成面板。提示：搜索开着时数字键是**打字**不是切
   热栏——想指定热栏位，先按数字再开面板。

## 战斗与食物

- **攻击**：左键按住挥击，伤害 = **选中物品**的 `attack_damage`（徒手/方块/
  材料 = 1，木镐 = 2，铁镐 = 3，**下界合金斧 = 5**，弓近战 = 1），命中 mob
   还会击退它。**打"中立"的 mob（下界的 piglin/hoglin）会激怒它**——它会
   追你 30 秒（见「传送门与下界」）。
  带**虚弱**效果时近战伤害相应降低（虚弱的徒手打出 0 伤害）。用镐/斧/铲
  打 mob 会额外磨损工具（耐久 −2/击）。
- **杀 mob 掉物品**（走近掉落物自动拾取，0.5s 拾取延迟；每只 mob 的数据可定义
  **多个掉落**，死亡时按列表顺序各掉一件）：

  | mob | HP | 掉落 | 备注 |
  |---|---|---|---|
  | zombie（夜晚/黑暗） | 20 | `rotten_flesh` ×1 | **食物**；不死族（免疫毒） |
  | skeleton（夜晚/黑暗） | 20 | `bone` 0–2 + `arrow` ×1 | 箭带**枯萎**效果（见下）；不死族 |
  | spider（夜晚/黑暗） | 16 | `string` 0–2 + `spider_eye` 0–2 | 近战命中上 15 s 毒；掉落为收集品（弓配方用木板不用线，记档） |
  | cow（任意光照） | 10 | `leather` + `beef` | 材料 + **食物**；可挤奶 |
  | sheep（任意光照） | 8 | `wool` 1–3（**出生毛色变体**）+ `mutton` | 材料 + **食物**；可剪毛/染色（见「蝙蝠与剪毛羊」） |
  | chicken（任意光照） | 4 | `feather` + `chicken` | 材料 + **食物** |
  | pig（任意光照） | 10 | `pork` 1–2 + `leather` 0–1 | **食物**；掉皮革区间（V2-5） |
  | bat（洞穴黑暗，飞行） | 6 | 无 | 悬停巡航不交互；吱叫声（见「蝙蝠与剪毛羊」） |
  | zombified_piglin（**下界**） | 20 | `rotten_flesh` ×1 | 敌对（zombie 同款数值）；下界专属 |
  | piglin（**下界**） | 16 | 无 | **中立**：不主动攻击，打它才追你 30 s；低语声 |
  | hoglin（**下界**） | 40 | `hoglin_meat` 1–2 + `leather` 0–1 | **中立**；大个慢速；**食物**（生 4/熟 8） |
  | magma_cube（**下界**） | 16 | 无 | 敌对；**不分裂不跳**（记档偏离） |
  | strider（**下界**） | 20 | `leather` 0–1 | 被动；**在熔岩海面上走路**（不怕熔岩）；嘶嘶声 |

  下界 5 种只在**下界**生成（独立生成池，主世界永不见；见「传送门与
  下界」）。

- **箭**（skeleton 掉落 / 燧石+木棍+羽毛 合成）：插在方块上的箭**走近即拾取**
  （1.0 块内，返还 1 支箭；飞行中的箭拾不了）；箭插着的**方块被破坏时箭会掉
  下来**（落地后可拾取）；插墙箭停留 100 秒后消散。箭命中的击退**随拉弓蓄
  力**变化——拉得越满击退越强（满蓄力 = 最强）。
  - **skeleton 的箭带枯萎**（SURV-5）：命中你 = 10 秒枯萎（每 4 秒掉 1 HP，
    **没有地板——能把你打死**）；被箭射中的 mob 也会中枯萎。
  - **毒弓（poison_bow）**：`弓 + 中毒药水` 工作台合成（shapeless）——射出的箭
    带 60 秒中毒（每 2.5 秒 1 HP，你还有 1 HP 地板，但 **mob 能毒死**）。
  - **僵尸/骷髅（不死族）免疫毒**（MC 同款）。
- **吃东西**：选中食物后**按住右键 1.6 秒** = 吃（3D 手部随进度抬向面部；
  **中途松开 = 取消不吃**，受击/死亡/解锁鼠标/开面板/换物品/左键挥击同样
  取消且**不消耗食物**；完成时回复该食物的饥饿 + 饱和度、消耗 1 个、播放
  进食音）。满饥饿时右键食物 = 无效果（仍吞掉该次右键）。

## 水/熔岩/蜂蜜桶（Phase 47，Phase 51 熔岩，FLUID-4/5/6）

- **舀水/熔岩/蜂蜜**：手持**空桶**右键**流体表面**（必须是"源头"——静止
  的一整格；流动的膜舀不到）= 流体被收进桶里，空桶变**水桶/熔岩桶/蜂蜜
  桶**（"splash" 音效）。一个空桶三种都舀（MC 语义）。隔着一堵墙/流动膜
  舀不到（准星先打到别的东西）。
- **倒水/熔岩/蜂蜜**：手持**满桶**右键**方块表面**（空地、不踩着自己）=
  倒出一格源头流体，满桶变回空桶。倒出的流体随后正常流动/扩散——倒在
  半空中它会落下来，倒在平地它会摊开。
- **倒向流动水面**（FLUID-4）：满桶对准**流动的膜**（非源头水）= 那一格
  **变源**（水不再流走，MC 同款"对着流水倒桶"）。对已源水/异种流体 =
  不发生（桶保留）。
- **桶 × 反应**（FLUID-5）：**水桶对准熔岩格** = 在受击面方向那格干空气
  放一源水，随即与熔岩反应成**黑曜石**（倒出的恒为源水）；没有空位
  可放 = 不发生（桶保留）。**熔岩桶对准水格** = 该格被熔岩源替换，随
  即与周围残留的水反应（源水 → 黑曜石、流动水 → 石头）。
- **水 + 熔岩 = 石头/黑曜石**（MC 同款，既有规则）：熔岩**挨着水**时反应
  ——挨着的是**源头水** → 黑曜石；挨着的是**流动水** → 石头。水不被消耗。
  熔岩会**发光**（夜里也能照出熔岩池）。
- **蜂蜜**（FLUID-6，MC 1.14+ 第三流体）：一种**黏稠流体，流动速度只有
  水的 1/3**（摊开/下坠都慢 3 倍），不引燃、不反应。来源 = **初始储物的
  蜂蜜桶**（1 个，桶是唯一获取途径——世界无蜂箱，记档偏离）；倒出后可
  再用空桶舀回。
- 桶**不能喝**（右键只舀/倒），桶永远不放方块。背包满时舀/倒不发生
  （点击被吞）。流体入存档（读档后你倒的水/熔岩/蜂蜜还在）。
- **下界没有水（V3-2 Part 2）**：在**下界倒水桶 = 水瞬间蒸发**——桶回空桶
  + 蒸发音，**不会留下任何水格**（MC 同款）；熔岩桶照常可用。
- 熔岩**会烧**（Phase 54）：站在熔岩格里**每秒受 4 HP 灼烧伤害**
  （Minecraft 速率，走正常伤害路径 = 红闪/音效/死亡全触发）；熔岩里移动
  比水里**明显更慢**（横移/上浮/下沉都是熔岩节奏）；掉进熔岩**取消坠落
  伤害**（与水同款）。碰熔岩还会**点燃**你（Phase 57 火系统，见上
  「燃烧」）：熔岩内直接灼烧 + 燃烧效果叠加（~9 HP/s，Minecraft 同款），
  **离开熔岩后继续烧 8 秒**，进水立刻熄灭。
- 熔岩**也烧 Mob 和可燃方块**（Phase 58）：Mob 踏入/接触熔岩即被
  **点燃**（每 0.2 秒掉 1 HP，与玩家同款节奏，能烧死；离熔岩继续
  烧 8 秒，进水熄灭）；可燃方块（作物小麦 7 阶 + 木头/树叶/草方块，
  Phase 63 = MC 天然可燃面）被熔岩 6-邻接触**烧成空**（无掉落）。

## 传送门与下界（V3-1/V3-2/V3-3/V3-14b，v3.2.0–v3.8.0/v3.20.0）

游戏有**第二个维度**：**下界（Nether）**——Minecraft 同款 8:1 坐标映射的
熔岩废土。

### 做传送门

- **框**：竖直平面的黑曜石环，外廓 **4×5 到 23×23**（高度恒 ≥5，"躺式"
  5×4 不算；**四角可以省**——环完整就行，最多省 4 块黑曜石）。
- **点火**：框建好后，用**燧石与钢**右键**框内空气**（准星对着环上朝向
  框内的面）= 内部全部变成**紫罗兰漩涡的传送门**（光 11，自持——火灭了
  也灭不了门）。**v3.16.0 起**：漩涡**流动**（纹理 UV 逐帧滚动）+ 门体
  周围升起**紫色蒸汽粒子**（氛围；距离 >4 块不发射——站近看）。
  也不消失）。
- **站入**：身体碰到传送门 = **1 秒倒计时**后传送到下界（倒计时中开面板
  自动关、走出去即取消）；抵达后有 **15 秒冷却**（别立刻折返）。
- **往返**：下界坐标 = 主世界 ÷ 8（Y 不变）——主世界 (0,0) 的门对应下界
  (0,0)；回去时自动在你附近 ±16 块搜活跃门，**找不到就给你生成一个新的
  4×5 门框 + 基岩平台**。
- **拆门**：破坏环上的黑曜石（**除了四角**）= 门消失回空气（MC 同款：角
  破了门还在）；传送门块本身生存不可直接破坏。
- 音效：进入 / 抵达 / 门周围的紫色低鸣。

### 下界什么样

- **没有天空**：暗红地平线、无日月星辰、无云无雨、无昼夜（时间照走但
  看不见）；F3 有 `dimension` 行显示当前维度。
- **地形（废土形态）**：脚下 = **netherrack 台地**（最常见块，硬度
  0.4）；**往下挖 21 格 = 熔岩海**（全静止源熔岩，别挖穿）；**头顶是
  70 格高的空腔**，顶部 y122 散布**萤石**（光 15）、再上是基岩顶。
- **5 种群系**（MC 比例）：**nether wastes**（台地基线）/ **crimson
  forest**（绯红菌丝地面 + 高大绯红菌柄柱）/ **soul sand valley**（灵魂沙
  谷地 + 灵魂土/岩浆块散布）/ **basalt deltas**（玄武岩柱林）/ **warped
  forest**（诡异菌丝 + 诡异菌柄）——绯红/诡异两种色调一眼可辨。
- **光照**：无天光；光源 = 熔岩海（15）/ 萤石（15）/ **岩浆块（3）** /
  传送门（11）/ 你放的火把（14）。**敌对生成门槛同款（光 ≤7）**。
- **灵魂沙减速**：踩在灵魂沙上走 = **移速 ×0.4**（疾跑也算，MC 同款）。
- **没有水**：下界倒水桶 = **水瞬间蒸发**（桶回空桶 + 蒸发音，不留水格，
  MC 同款）；熔岩桶照常。
- **炉子/工作台面板主世界专属**（下界开不了，记档偏离）。

## 建筑材料（V3-5，v3.9.0）

## 营火（campfire，Phase 71；P75-78 四槽/浇灭/再点燃/全图标）

## 楼梯（stone_stairs，Phase 87/89/92/97）

工作台用 `6 个石头`（台阶形 S/SS/SSS）合成 **4 个石楼梯**（4 个朝向块
各一个配方）。楼梯 = **可以爬上去的斜面**，站在上面脚的高度随站的
位置变化（越靠斜面低端越低）。
**放置时自动朝向你**（低端朝你的视线方向，Phase 97）；**潜行 + 右键 =
原地旋转**到下一朝向（Phase 92，循环 N→E→S→W）——放错了不用拆重放。

## 台阶（stone_slab，Phase 85 / V2-17）

工作台 `3 个石头`（横排一行）合成 **6 个石台阶**。台阶 = **半高的石头**。
**放法（MC 同款）**：对着**块顶面**放 = 底部台阶（矮石台，站在上面）；
对着**块底面**（天花板）放 = **顶部台阶**（悬在上半格）；对着**侧面**放 =
看准星在目标格的上半还是下半——**上半 = 顶部台阶、下半 = 底部台阶**。
**同格互补台阶再放一次 = 合成整块（双台阶）**——占满整格、可站可盖；
**破坏整块掉 2 个台阶**（材质守恒）。双台阶是放置合并产物，不可直接合成
（MC 同款）。台阶**不旋转**：潜行+右键对台阶不生效（它的状态是"在上半
还是下半"，不是朝向——楼梯的旋转环不受影响）。**台阶/楼梯/墙/栅栏不挡
光**（LGT-5：光照当它们不存在——垫高地面不会让下面变暗）。

## 信标（beacon，Phase 83；P91 双效果；LGT-4 光束昼夜）

信标 = **持续效果来源**（金苹果之外）。
- **做法**：① 工作台 `9 个铁锭`（3×3 格）合成 1 个**铁块**（MC 同款）。
  ② 在 3×3（或 5×5/7×7/9×9）的**铁块基座**正上方放一个**信标**。
  ③ 站在信标 **50 格内** → 同时获得**吸收层（4 点红心池）+ 速度
  （移动 1.2×）**（P91：MC 主 + 副双效果）。
- **基座越高越强**：完整 3×3/5×5/7×7/9×9 层 = 等级 1/2/3/4（缺角的层
  只算到最低完整层；**无基座 = 无效果**）；等级 4 光束最长。
- **光束**：信标发射一道**半透明青色光束**到天空（`beacon.beam` 关则无
  光束）；**光束颜色随昼夜变**（深夜月光下变暗，LGT-4）。
  光束不照亮周围（MC 会；项目文档化偏离），信标块本身不发光。
- 信标 + 铁块**不入世界生成**（只经放置/合成），**入存档**（块编辑，
  读档重建；功率等级每帧从基座重算、无独立状态）。

## 存档（SAVE-1/3；V3-7 gzip；V3-1 format 30）

- **自动存档**：`--save` 运行时，**每 2 分钟自动存档一次**（代码默认
  120 s；`config.json` 的 `save.auto_save_seconds` 可改，0 = 关闭；
  当前配置无覆盖 = 默认 2 分钟）。
- **手动**：`F5` 立即存档（`--save` 运行时）；**退出时自动存档**。
- **压缩（V3-7）**：存档文件**默认 gzip 压缩**（同世界逐字节可复现的确定
  性容器，实测体积 ~1/5–1/6）；`config.json` 的 `save.compression:
  "none"` = 明文（调试用）。**旧版明文存档零迁移**——加载时自动探测，
  旧档直接读、新写自动压缩。
- **下界维度数据（V3-1，format 30）**：存档现在包含**你所在的维度**
  （主世界/下界）与**下界世界段**——你在下界的破坏/放置/传送门都持久化
  （读档回下界照旧；mob 依然不入档）。

## demo 回放（V3-9，v3.11.0）

把你的游玩**录下来、回放出**——或者纯手写一段动作时间线。回放是**只观
察**：你（观众）转镜头/切视角/变速/暂停，**demo 里的"你"由录制时的输入
驱动**，观众操作结构性碰不到世界。**看演示比读文字直观**——仓库自带
4 个预设教程 demo（新种子 123456789，确定性重演，随时可看）：

| demo | 看什么 | 命令 |
|---|---|---|
| `example.dmo` | **基础操作**：锁指针 → 边走边挖（按住左键 + 掉落磁力拾取）→ 开关背包 → 第三人称 → 滚轮缩放 | `./build/bin/tokenmine --demo assets/demos/example.dmo` |
| `tutorial_dig.dmo` | **挖掘升级**：低头连挖 6 格（草→土×3→石头×2），中途**按 `9` 换木镐**（石头 ×2 效率），锻石/泥土被磁力吸进背包，终点在洞底抬头 | 同上，换文件名 |
| `tutorial_build.dmo` | **建造入门**：数字键 `7`/`1`/`8` 切换玻璃/石头/萤石，围绕自己**放一圈 4 块**（N 玻璃/东石头/南萤石/西玻璃），结尾镜头环绕 + 三视角切换 | 同上 |
| `tutorial_fly.dmo` | **飞行**：**双击 Space** 起飞（MC 创造同款手势）→ 按住 Space 升空 → `W` 巡航 → `Shift` 降落 → 再双击 Space 落地 | 同上 |

回放中你（观众）可以随时**转镜头、`C` 切视角、滚轮 0.5×/2× 变速、`ESC`
暂停看细节**（`Q` 退出）——同一个 demo 从任意角度看。想学录制/编写：

- **三个入口**（命令行，互斥）：
  - **录制**：正常玩时加 `--demo-record [输出路径]`——你所有输入事件 + 每
    帧时长被捕获，**退出时存成 `.dmo`**（默认 `data/demos/rec_<时间戳>
    .dmo`）。
  - **回放**：`--demo 某个.dmo`——从文件记录的**世界起点**（新种子或存档
    槽）+ 帧时长序列 + 输入事件流**确定性重演**。回放**永不回写**引用的
    存档槽（观察红线：槽 md5 前后逐字节不变）。
  - **兼容性**（v3.13.0 起独立 `sim` 版本号，模拟语义版本独立于游戏
    版本）：纯渲染/内容/文档升级**不 bump** = 你的 demo 持续可放；模拟
    语义变了（如 v3.14.0 手柄按键重映射 = sim 1 → 2）时旧 .dmo **点名
    拒收**并提示 `--demo-force` 强制试放（带警告；**纯键鼠录制的 demo
    强制回放行为恒等**，只有含手柄事件的录制才真受影响）。
  - **编写**：`--demo-author 时间线.json`——手写动作时间线（键按下/抬起、
    鼠标、持有时长）展开为 `.dmo`，headless 即出（游戏不启动）。
- **观众操作**（回放中，全部不触达模拟）：
  - **鼠标/手柄摇杆** = 绕着玩家眼睛**转镜头**（自由 orbit——demo 的瞄准
    射线仍是"录制的你"的朝向，你转镜头不偷它）；
  - `C` = 切第一/第三人称；
  - **滚轮**（或手柄 LB/RB）= 速度 **0.5× → 1× → 2×** 循环；
  - `ESC` = **暂停/继续**（暂停时 `Q` = 退出回放；放完 = 停在末帧观察态，
    `ESC` 收起面板继续看、`Q` 退出）。
  - 暂停/结束有暗帷面板（标题/文件名/速度/提示）；平时右上角有 **DEMO
    x速度** 角标。
- **确定性**：`--frames N` 按**模拟帧**计（任意倍率同一终态）；0.5× =
  同一 demo 帧渲染两遍（模拟不双推）；慢机器掉渲染帧不影响模拟结果。
- **文件**：`.dmo` = 与存档同款确定性 gzip 容器 + 严格 schema（独立 sim
  版本不匹配点名拒收 + `--demo-force` 逃生门、事件类型封闭 8 词表、乱序/
  损坏点名）；仓库自带示例 `assets/demos/example.dmo`（294 B：走 50 帧 +
  挖 2 块 + 开背包 + 切视角 + 缩放）。
