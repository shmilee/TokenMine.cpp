## ① 接缝残留 = 边界处亚像素相位差（overlap 混合带结构根除）

- **诊断链（门内实证，三步）**：
  1. v3.50 的 45° 水平 tile 精确后 yaw 数学严格（互相关无系统偏
     移、显示面 wrap 屏位 0.0 差 = GL_REPEAT 无驱动级错位）；
     但每个 tile 的**边缘列恰在视锥裁剪面上**（fragment 部分覆盖
     AA = 边界梯度 1.7x 系统偏高）→ 第一修 = **overlap 捕获**：
     每向渲染 48°（kPanoramaHfovRenderDegrees = 45 + 2×1.5°），
     拼接取中央 600 px（keep = 640·45/48 整除，static_assert 钉
     非整数红线）——每列来自视锥内部，strip 4800×360。
  2. overlap 后互相关仍无偏移，但 wrap 处高对比内容（云边/岩石
     边）仍读得出接缝 → 试 **yaw minimax 偏移**（让 8 条边界方位
     避开高对比内容）：两次门内捕获否决——成本函数**符号反了**
     （64 百分位复现）+ **前景视差破坏循环平移假设**（28.2° 后
     wrap 反升 88 百分位）：内容边缘无法靠旋转「避开」全部 8 条
     边界（密林 + 块状云全方位高对比）。
  3. 最终根因 = **亚像素相位**：同一条边界射线在两个 tile 的像素
     网格上落点相差半列——硬边缘内容在边界处读成 1px 台阶（软内
     容无感，硬边缘即「接缝」）。
- **修 = 边界混合带**（kPanoramaBlendHalf = 12，结构通用、零调参）：
  每条边界（7 内部 + wrap）两侧各 12 列 = 24 列混合带：strip 原列
  （on-grid 采样）与**邻 tile 对同一射线的渲染**（overlap margin 的
  half-phase 采样）线性混合（α 从 0.02 到 0.98 跨带）——同相机同
  射线仅差亚像素相位，混合 = 硬边缘的 1px 台阶变成真抗锯齿斜坡，
  无特征区 = no-op（α 端点 0/1 = 原列，C0 连续）。**任何场景、任何
  种子、任何边界方位的结构无缝**（不再依赖内容布局）。
- 门断言 = **spine belt**：每条边界的列对对比度 ≤ 1.5× 邻域
  ±15 列中位数（无尖峰；绝对百分位是错指标——高对比场景的合法
  边缘可近边界，见 PITS 433②）。
- 资产再生 4800×360（×2 字节恒等，committed）；菜单显示面零改动
  （uSpan/pan 全用纹理尺寸通用式，4800 自适应）。
