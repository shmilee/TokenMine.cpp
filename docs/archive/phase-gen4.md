# Phase GEN-4 — 洞穴破碎度（v1.0 任务表 19/31，门 100）

> 用户报障（10-25）："现在的洞穴数量太多、太碎了，经常碰到很小的洞穴，
> 体验太差"。代理定案 = GEN-1 面条洞穴参数重标定（纯数据，零核心）。

## 实现内容

**`caves.noise_scale`: 0.09 → 0.05**（`tube_threshold` 0.06 保持；worldgen.json
唯一内容变更）。噪声特征周期 ~1.8× 变大 = 管体更粗更长、小口袋并入主管；
t 不动 = n2 短路求值率与旧参数持平 + 不加密度（0.05/0.07 聚合 6.55% 出带
= 证否）。

**标定方法**（探针 `tests/cave_probe.{hpp}` + 独立驱动 `build/bin/cave_probe`）：
- 真实资产驱动，`WorldGenerator::create` 工厂直接实例化候选参数（零可测试
  构造面新增）
- 样本 32×32 列（设计标准）× 全高 + **96×96 交叉验证**；seed 集
  {123456789, 9, 42} 全网格 + seed 7 抽查；区域构造上避开出生清除区与
  全部熔岩湖盒（统计 = 纯洞穴）
- 统计 = 26-邻洪泛连通域：挖除率 / 域数 / 体积 p50·p90·max / **<8 格
  pocket 占比** / 表面洞口数
- **方法论修正**（入测试注释）：单 seed 挖除率摆动 ±1.5pp（32×32 噪声
  主导）= 选择规则按 **3-seed 聚合**应用 + 96×96 双样本一致验证
- 选定规则（设计定案）：聚合挖除率 4-6% 带内 + pocket 格最少 + 域数
  最少（并列取 cs 偏离最小）

**标定结果**（96×96 四 seed 聚合；`./build/bin/cave_probe 96` 可复跑 ~5 s）：

| 参数 | 挖除率 | 域数 | pocket(<8格) | 中位洞体积 |
|---|---|---|---|---|
| 0.09/0.06（旧） | 5.82% | 35 | 110 格 | 12-42 格 |
| **0.05/0.06（定稿）** | **5.12%** | **8** | **10 格（−91%）** | **392-1554 格（9-130×）** |

= "更少、更大"直击报障三点（太多→密度 −12%、太碎→域数 ÷3-5、小洞
频繁→pocket −91% + 中位体积 9-130×）。
